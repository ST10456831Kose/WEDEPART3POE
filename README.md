# Kay Lashes Website - WEDE5020 Part 3

## Changelog (Part 3 Updates)
*   **Converted to Multi-Page Website:** Separated the single-page design into `index.html`, `products.html`, `enquiry.html`, and `contact.html`.
*   **JavaScript Lightbox Gallery:** Added an interactive image gallery on the Home page.
*   **Dynamic Content & Search:** Implemented a live search bar on the Products page that filters products in real-time.
*   **Form Creation & Validation:** Created `enquiry.html` (for bookings) and `contact.html` (for general messages). Used JavaScript to validate inputs and simulate AJAX submission.
*   **SEO Optimisation:** Added unique title tags, meta descriptions, and relevant keywords to all pages. All images have descriptive alt attributes.
*   **Responsive Design:** Applied CSS Media Queries for mobile and tablet devices.
